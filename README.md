🏙️ JAN-DRISHTI-AI | CivicTrace

Smart Civic Complaint Management & Tracking Platform

JAN-DRISHTI-AI (CivicTrace) is a civic-tech platform designed to help citizens report local civic issues, track complaint status, and improve communication between citizens and authorities.

The project aims to make civic complaint management more accessible, transparent, and efficient through a digital platform.

✨ Key Features

- 📝 Civic Issue Reporting
- 📍 Complaint Tracking
- 📊 Complaint Management
- 👥 Citizen-focused Platform
- 🤖 AI Integration (Gemini API)
- 🎨 Modern User Interface

🎯 Project Vision

To bridge the communication gap between citizens and authorities by providing a digital platform for reporting and tracking civic issues.

🛠️ Technology Stack

- Frontend: React 19, TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- AI Integration: Google Gemini API SDK
- Backend Dependencies: Express.js
- Animations: Motion
- Icons: Lucide React

🚀 Getting Started

Prerequisites

- Node.js
- npm
- Git

Installation

1. Clone the repository:
   
   git clone https://github.com/pranavkumarshukla242-cmyk/JAN-DRISHTI-AI.git

2. Navigate to the project directory:
   
   cd JAN-DRISHTI-AI

3. Install dependencies:
   
   npm install

4. Configure environment variables using ".env.example".
   
   Add your Gemini API key if required.

5. Start the development server:
   
   npm run dev

6. Open the local URL shown in your terminal.
